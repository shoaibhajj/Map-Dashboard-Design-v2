# GPS Dimension — futuristic depth with an engineering budget

Applicability guard: if the current request has no visual/interaction/design-session intent, do not load the design context merely because GPS/IoT is mentioned. Return to the ordinary task workflow. Honor read/propose/review-only mode before any write.

Read context/design/ENTRY.md, BRAND.md, DEPTH-PERFORMANCE.md and current target/dependencies. Follow the user's explore/execute mode; this procedure is not blanket permission to install a renderer.

## Steps

1. Define what dimensionality explains: physical device, spatial zone, asset state or another real relationship. Identify why a flat diagram might not suffice.
2. Compare D1 CSS/SVG, D2 pre-rendered image/video and D3 real-time scene. Select the lowest adequate tier; D0 is acceptable when it better serves the task.
3. Specify camera/material/light/interaction, source and rights, static initial meaning, accessibility text/controls, load boundary, reduced-motion/touch behavior and error fallback.
4. Check current installed libraries; estimate asset and JS cost separately. Proposed budget is not measured evidence. Ask for necessary dependency/paid-asset approval.
5. For authorized implementation, isolate changes; lazy-load expensive code, reserve dimensions, avoid per-item canvases, prefer resting/on-demand rendering and pause hidden/offscreen decoration. No per-frame React state churn. Don't place decorative shaders over the operational map.
6. Measure baseline/after in the same environment where tools permit. Test renderer/asset failure, repeated navigation, coarse pointer and modes. Report unmeasured areas.

## Output

Chosen technique / alternatives rejected / scene brief / asset license / loading & static fallback / estimated vs measured cost / checks and limitations.

If the design only works with heavy effects, simplify concept before optimizing a wrong implementation. Never claim zero impact or a guaranteed FPS across devices. Use context/design/templates/concept-card.md for major scenes, not mandatory documentation for a small shadow change.
