## Verification procedure

1. Install to a safe project/branch using preview first; merge router.
2. Check skill discovery with host controls, not guesswork.
3. Start a fresh host session if needed. Try positive and negative prompts independently to reduce contamination from previously loaded skills.
4. Observe actual files read and tools/actions, not only the answer claiming correct routing.
5. A manually explicit skill may be honored even for odd content; the skill should detect mismatch and return to ordinary workflow rather than invent a design task.
6. Record failures; adjust descriptions/router scope if false positives happen. Descriptions reduce errors, not a deterministic classifier.
